# كوتشال · معاينة المتجر

واجهة عربية متجاوبة للأكوات والشيلان الرجالية، تستخدم صور كوتشال وشعارها. يختار الزائر المقاس والكمية، ويراجع رسوم التوصيل، ويسجّل طلبًا تجريبيًا بمرجع تحويل بنكي أو محفظة.

## التشغيل

يتطلب المشروع Node.js 24 أو أحدث.

```sh
npm ci
npm run dev
```

تظهر المعاينة على [المنفذ 5173](http://127.0.0.1:5173). لتشغيل النسخة المبنية محليًا استخدم `npm run build` ثم `npm start`. يظهر عنوانها على [المنفذ 4173](http://127.0.0.1:4173).

## تجربة الطلب

1. اختر قطعة من المِشجب وافتح صفحة المنتج، ثم اختر اللون إن توفّر والمقاس وأضفها إلى السلة.
2. اختر منطقة التوصيل واستخدم اسمًا ورقمًا وعنوانًا وهميين.
3. اختر تحويلًا بنكيًا أو محفظة وأدخل مرجعًا مثل `DEMO-12345`.
4. بعد التأكيد يظهر رقم يبدأ بـ `CS-` وحالة «بانتظار مراجعة التحويل».

الأسعار والمقاسات والمخزون ومناطق التوصيل تجريبية. مرجع التحويل للتجربة فقط. إعداد المتجر الفعلي يحتاج بيانات المنتجات والتوصيل وتعليمات حساب التحويل المعتمدة.

## إدارة الطلبات التجريبية

```sh
npm run orders -- list
npm run orders -- confirm CS-XXXXXXXXXXXX
npm run orders -- reject CS-XXXXXXXXXXXX
```

استبدل الرمز برقم الطلب. يعيد رفض الطلب المعلّق كمياته إلى المخزون. يحفظ SQLite البيانات في `data/coatshal.sqlite` محليًا. يمكن تعيين `COATSHAL_DB` لتغيير مسار قاعدة البيانات. استخدم المسار نفسه عند تشغيل الخادم وأوامر إدارة الطلبات.

## التحقق

```sh
npm test
npm run build
```

تغطي الاختبارات حفظ الطلبات بعد إعادة التشغيل، وتكرار الإرسال، والتحقق من السعر والمخزون وطريقة الدفع، وإعادة المخزون عند رفض التحويل.
